# Les petits lecteurs

Trois jeux de lecture pour les 5-10 ans (Petit Astronaute, Casmo, Le Labo des petits lecteurs), sur iPad ou ordinateur. Lien réservé aux personnes qui l'ont reçu ; le Labo demande le mot de passe envoyé avec le lien. Aucune donnée n'est collectée, les profils restent dans le navigateur.
