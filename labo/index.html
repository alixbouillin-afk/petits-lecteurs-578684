Mon carnet de mots

Réglages (parents)

Son

Le Labo lit les syllabes à la voix : sur iPad, vérifie que le mode silencieux est désactivé et le volume monté.

Le carnet ne peut pas être sauvegardé sur cet appareil.

Niveau du joueur

🐣 Petits : mots de 2-3 syllabes simples (va-che, to-ma-te). 🦁 Grands : tous les mots (sons complexes, syllabes fermées, mots longs).

Taille des syllabes

Mode d'emploi : glisser une syllabe vers une autre ; si elles forment le début d'un mot du monde, elles s'aimantent (toujours dans le sens de la lecture) ; sinon elles se repoussent. Toucher une syllabe = l'entendre. Toucher un bloc = le réentendre, puis ✂ pour le détacher. Un mot complet ouvre sa fiche. Un s bleu (se, sau, sin, sée) se lit « z », entre deux voyelles.

Sur iPad : installer le Labo sur l'écran d'accueil (Partager → Sur l'écran d'accueil) AVANT de créer les joueurs — l'app installée et Safari ont chacun leur carnet, et Safari efface le sien après 7 jours sans visite.
